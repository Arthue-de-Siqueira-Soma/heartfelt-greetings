GUIA RÁPIDO / LITEMATICA

Leve a construção para o seu mundo.

Siga estes passos para carregar um schematic no Minecraft Java usando o mod Litematica. Os nomes dos menus e os requisitos podem variar conforme a versão instalada.

PASSO 01

Baixe o arquivo

Abra o link do projeto no catálogo e baixe o arquivo disponibilizado pelo criador. Se vier em ZIP, extraia o conteúdo e procure um arquivo .litematic.

PASSO 02

Coloque na pasta

Copie o arquivo para .minecraft/schematics. Se a pasta não existir, crie-a. Se você usa um launcher com instâncias separadas, utilize a pasta de jogo da instância correta.

PASSO 03

Carregue no jogo

Abra seu mundo, entre no menu do Litematica (a tecla padrão costuma ser M), escolha Load Schematic e selecione o arquivo. Depois, posicione o holograma da construção.

Atenção: confira a versão do Minecraft e os requisitos do projeto. Farms de redstone e de aldeões podem funcionar de forma diferente entre versões. Teste projetos complexos em um mundo separado antes de usá-los no seu survival.
