Comunidade CraftBase

Comentários e ideias.

Este é o espaço para reunir comentários, dúvidas, sugestões de novas farms e construções, avisos de problemas e ideias para melhorar o CraftBase. A conversa é compartilhada com todos os visitantes.

Como funciona

Os comentários são guardados em uma conversa pública ligada ao repositório do CraftBase, em vez de ficarem salvos apenas no seu navegador. Assim, a discussão pode continuar mesmo quando mais pessoas começarem a usar o site.

CompartilhadoTodos os visitantes veem a mesma conversa e as mensagens publicadas.
Conta GitHubPara publicar ou responder, entre com sua conta GitHub no sistema de comentários.
Respeito à comunidadeNão publique senhas, dados pessoais nem conteúdo ofensivo. As mensagens são públicas.

Discussão da comunidade

Leia e publique comentários nesta própria página. Para enviar uma mensagem, o Utterances pode solicitar que você entre com uma conta GitHub.

Abrir também no GitHub ↗

Os comentários são públicos e podem ser moderados no GitHub. Para habilitar a caixa de comentários, o proprietário do repositório precisa instalar a aplicação Utterances neste repositório. Se a caixa não carregar, use o botão “Abrir discussão no GitHub”. Para publicar pelo site, pode ser necessário autorizar a aplicação com sua conta GitHub.
