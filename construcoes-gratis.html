Como funciona: o arquivo é montado localmente no seu navegador com blocos vanilla do Minecraft. O site não usa IA, não manda sua ideia ou imagem para nenhum servidor e não precisa de API paga. Estes são modelos iniciais, não construções inventadas a partir de uma captura de tela. O gerador usa como alvo o Minecraft Java 1.21.8; teste o schematic no Litematica antes de usar em um mundo importante.
